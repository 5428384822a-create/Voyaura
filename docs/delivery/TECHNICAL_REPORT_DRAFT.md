# 参赛技术报告初稿：Voyaura

项目：基于证据约束的私人旅行规划与记忆工作流。版本：本地受控验证版。开发分支codex/xiaoxi-evidence-agent；基线cbdab47。正文由Codex根据实际代码与运行结果整理，CodeArts真实证据尚未完成。

## 问题与目标

攻略文本容易混淆建议与事实，旅行的时间、预算和开放条件又会互相约束。旅行后，照片和日记分散且私人资料不应被自动外传。Voyaura围绕“规划—陪伴—记录—创作”的原始愿景，先实现可检查的日间行程草案与授权记忆整理两条闭环。

## 实现方案

保留Vue3/FastAPI/SQLAlchemy与现有媒体体系，新建显式任务状态机。默认有限规则提取兴趣，可选DeepSeek只返回受限检索关键词；通过高德获取地点/交通，严格核对坐标与来源。用户主动输入的地点保留未经独立核验标签。规划器按天分组并日内排序，独立验证器读取最终时间线检查必去、结束时间、已知开放与费用下界。

信息不足不能保存；硬冲突需要调整；未覆盖完整交通、住宿、餐饮、预约条件时保持条件草案。用户修改会增加版本并使旧确认失效。服务端确认绑定用户、内容摘要和期限，数据库CAS与唯一约束防止重复正式写入。

故事工具只读取已授权城市/日期的现有文字、日期和ready/clean媒体数量，不能识别照片内容，也不生成虚构到访。用户编辑后再次核对来源并确认。未确认来源变化会撤回正文；已确认故事成为独立私有快照，源删除不自动删除其快照。

## 创新价值

本版的可展示价值为事实角色分离、条件草案、可观察工作流、内容绑定确认和授权记忆闭环。它将用户体验中的“需要核实”与底层证据保持一致，避免把成功返回文本当成完成任务。尚未完成立项书中的完整约束优化、学术对照、语音与长期画像，未作算法领先或量化增长承诺。
