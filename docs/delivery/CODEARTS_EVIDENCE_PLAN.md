# CodeArts真实工作与证据收集方案

## 当前事实

本次工程调查、代码、测试和材料由Codex及其独立子智能体完成。**尚无本次真实码道使用证据，也没有资格据此宣称满足“码道作为核心AI编程工具”要求。**本文件只是后续工作方案，不是使用证明。不得把Codex截图、提交、日志改名放入codearts_proof。

官方规则快照检查时间2026-11-22，赛题明确核心AI编程工具与真实痕迹。剩余时间短，应先向主办方确认已有Codex工程叠加真实CodeArts开发的接受口径；不能只补几张启动截图就声称“核心开发已使用码道”。

## 必须由真实CodeArts承担的实质任务

在本开发分支基础上另建可审查分支，由开发者在实际码道IDE/Agent Space执行、验收、提交：

1. **约束规划改良**：实现并比较每日容量/必去锁定的跨日relocate/swap修复，保留输入证据；不能把计划写成已完成。补不满足开放/预算时的解释与独立验证，记录修改文件和真实运行。
2. **自然语言约束澄清**：在明确城市/日期/预算字段优先的前提下，设计受限结构化提取与冲突追问；缺参数进入needs_input，不能让模型凭空生成坐标/票价。补异常JSON、权限和冲突测试。
3. **联调与质量修复**：根据本交付未验收项完成一次真实授权高德联调与可复现故障记录；或实现并验收旧媒体任务的租约/ACK恢复。若服务额度或权限不足，如实保留失败与未完成。

前两项为本项目核心规划链路，建议实际由码道持续承担需求、代码生成、调试、测试与文档；任务范围按剩余时间择其能完整验收者，不为凑证据仓促并入未测试代码。涉及收费Provider仍需用户授权，不自动消费。

## 每项证据

- 实际工具名称/版本、开发者、开始结束时间、分支和任务编号。
- 原始Prompt、真实AI交互与代码生成/重构/排错截图，清楚显示码道界面；原图不篡改来源。
- Git修改前后commit、diff、修改文件和与Prompt对应关系。
- 实际测试命令、退出码、日志与修复迭代；线上/回放/替身分开。
- 功能Demo录屏及开发过程录屏，注明哪些环节是CodeArts、Codex和手工完成。
- 截图前遮盖密钥、令牌、手机号、个人邮件、真实旅行隐私；保留无秘密的上下文，不能因脱敏改变操作事实。

建议证据目录（仅在真实产生后创建文件）：`codearts_proof/任务编号/{session.md,prompts.md,screenshots/,diff.patch,test-results/}`。本交付不填充虚构占位截图。
