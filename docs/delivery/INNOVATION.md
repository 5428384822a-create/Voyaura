# 原创场景价值与差异化分析

Voyaura延续原立项书的私人旅行记忆定位，优先服务独行、低规划负担、重视回忆表达的用户。场景价值是把“我想怎样旅行”连接到可编辑的每日安排，并把旅行后的真实文字和日期连接到私有故事，而非只产出一篇流畅攻略。

## 已实现的产品与工程特色

1. 事实角色分离：有限规则／可选模型提检索主题，高德核地点与交通，确定性规划器安排，独立验证器检查。坐标、票价、开放等未知信息不被模型补齐。
2. 条件草案语义：用户地点始终显示user_provided；交通未知用30分钟规划缓冲并显式标记，不把0当已核实，也不将景点均价当门票。费用下界与完整旅行预算分开。
3. 有证据的行动：任务、来源、调用尝试、错误、编辑版本、确认摘要和档案均落库；中断以失败收束，不伪造已执行状态。
4. 旅行记忆闭环：只在授权城市和日期读取现有记录，空数据不造经历；可编辑后重新确认，来源变化撤回未确认草稿。照片只计可用数量，没有声称视觉理解。
5. 用户控制：外部/模型调用分别授权；正式保存需有时效的内容确认，保存计划不点亮地图、不买票、不发布。

## 与常见方案的比较口径

以下是架构类型比较，不是对某家产品的在线实测，也不声称竞品均缺少这些功能。

| 类型 | 通常优势 | Voyaura本版侧重 |
| --- | --- | --- |
| 通用对话生成 | 灵活表达与开放问答 | 结构化约束、外部证据、确定性检查和可审计写入 |
| 地图/导航 | 地点与道路信息 | 将有限候选按天组织，显式处理信息不足；底图和交通仍依赖地图Provider |
| OTA/预订平台 | 交易、库存与商业供应链 | 本版专注规划和私有记忆，不提供预订能力，不宣称替代OTA |
| 日记/影像工具 | 记录与内容表达 | 授权记录变为可编辑故事，并保存来源和确认版本 |

## 尚未证明的研究假设

立项书中的约束k-medoids、真实有向交通矩阵、跨日relocate/swap/ILS、OR-Tools精确解gap、多轮偏好记忆、语音情感适配、RAG授权内容，均未在本次实现或实验完成。当前分组＋近邻启发式不等于这些算法，更不能宣称全局最优、降低多少耗时或提高多少满意度。

下一步实验应冻结相同候选、交通证据、时间/预算约束和计算预算，对比普通坐标分组、当前启发式、约束优化；分别测硬约束通过率、未知信息误判率、总交通时间、保留已锁地点比例、运行时间。线上真实服务与离线回放分开记录；没有实验就不填效果数字。

原始立项书引用TravelPlanner、ReAct、个性化旅行与动态规划工作，说明工具使用和反馈修复已有研究；本项目应把原创性表述为具体证据与交互设计的候选价值，而非“首次提出旅行智能体”。
