# Demo演示流程与解说词（约3分钟）

准备：按RUNBOOK启动本机服务，使用自己的访问令牌连接；没有密钥也能演示。候选和文字样例应在画面上标“验收输入，非真实旅行”；不要展示令牌或个人原始立项书。完整可重复验收用隔离verify_e2e.py，截图来源见TEST_REPORT。

| --- | --- | --- |
| 0:00—0:20 | 打开地图与小曦行程页 | “Voyaura把规划和回忆连起来。本次展示真实本地服务与数据库；下面是明确录入的验收样例，不是高德在线查询结果。” |
| 0:20—0:45 | 填目标、城市、日期、2天、节奏；填写4个有坐标候选 | “想法与硬约束分开。没有地图凭证时，只使用我主动提供的候选，来源保持未经核验；不会捏造景点。” |
| 0:45—1:15 | 生成、点击Day1/Day2、看地点示意与时间线 | “工作流已执行候选去重、按天分组、日内排序和独立检查。虚线是顺序示意；交通未知保留未知，只留明确缓冲。” |
| 1:15—1:40 | 每日结束改16:00、重排；展开检查与执行记录 | “修改会产生新版本并重新检查。已知费用只是下界，完整交通、开放和预约仍需核实，所以这是条件草案。” |
| 1:40—2:00 | 预览、主动勾选、确认；刷新后最近任务恢复 | “预览不是保存。确认绑定当前内容与版本；重复请求不会多写档案，保存计划也不会伪造城市足迹。” |
| 2:00—2:35 | 转故事页；授权已有验收文字；改标题正文并保存修改 | “这里只读我授权城市与日期的现有文字、日期、可用照片数量，不声称看懂照片，也不外传私人记录。空记录只提示信息不足。” |
| 2:35—2:50 | 再次确认故事 | “来源变化会撤回未确认草稿。确认后的故事是独立私有快照，删除来源不会自动删除故事。” |

若工具失败，直接展示状态与错误，说明缺少什么、可补什么；不要临时切假响应冒充成功。若有真实高德Key并获授权，可改为在线搜索，保留来源和查询时间；模型只允许辅助关键词，不把其文本当事实。

## 第三轮前端更新后的走场（约2分钟，可接在行程展示后）

1. 打开“旅程”：地图与城市档案并列。无Key时说明底图不可用，仍可浏览档案。若需新建演示记录，仅在隔离库手动选城，先展示预览不会点亮，再主动确认；不要为演示向个人档案自动填数据。
2. 打开城市档案：展示手动来源、首次／最近记录时间；写入明确“本地验收·非真实旅行”的日期和文字，先预览再确认。解说：“原始记录先由我提供并核实。”
3. 点击“整理这座城的故事”：展示已带入城市和记忆日期、默认关闭的读取授权。勾选后生成，展开原文来源、编辑，再确认保存。解说：“小曦把已有记录组织起来；没有资料就请我补充，不补编经历。”
4. 返回城市记忆书架，展示搜索与年份活动筛选；再进入创作页。解说：“自己的照片与衍生作品保留关联。当前生成服务未连接，所以这里展示真实空状态与选照片的路径。”装饰摄影明确为灵感参考，不称生成作品。
5. 展示69项前端、14项真实浏览器及四页四屏宽检查。在线高德、媒体处理／生成、CodeArts实际工作仍独立留证，不将本轮UI或Codex记录替代它们。

## 第四轮新增衔接演示（约45秒，可作为开场或收尾）

1. 打开“我的”：访客先看三条真实使用引导；连接后展示实际统计与服务配置。解说：“从规划、抵达或记忆任选一个入口，按需连接私人档案。”录屏时勿展示令牌。
2. 在独立验收库的最近任务中打开明确标注的测试行程，展示版本与原结果，再刷新。解说：“读取原任务，不重复执行；是否正式保存仍由我决定。”
3. 修改一段测试输入后点击“我的”，选择继续编辑，展示文字仍保留；再主动放弃后回总览。解说：“不会在跨页时悄悄丢掉编辑，也不自动存一份私人正文。”
4. 展示80项组件／客户端及18项真实浏览器验收。当前服务截图保护私人文字，完整流程使用独立测试库；云服务与CodeArts仍单独留证。
