# Voyaura 最终独立质量审查

审查日期：2026-11-22。对象为本任务开发分支当前工作区，不是原始基线。基线另见 `BASELINE_CODE_AUDIT.md`。审查员只修改独立对抗测试和本报告，没有修改业务代码、读取桌面密钥、运行收费模型或提交 Git。全量回归、真实 HTTP、桌面及移动端浏览器验收和最终提交由主负责人执行。

## 结论与验收边界

在本地单机 owner 身份、隔离 SQLite、无真实云端凭证的范围内，所检查的后端 Agent 边界通过独立对抗测试。现在已有持久化任务、按天规划、独立约束检查、工具及错误记录、内容确认和私有档案写入。

默认意图处理仍是明确标示的有限关键词规则；故事是对用户已有文字、日期和可用媒体数量的本地整理。不能宣传为已验证的大模型自然语言理解、照片视觉识别或通用自主智能体。可选 DeepSeek 与高德 Provider 已有代码，本审查没有进行真实在线调用。完整交付仍以主负责人最终 `TEST_REPORT.md` 的全量回归及浏览器结果为准。

## 实际运行的独立测试

在 `api/` 实际执行：

```powershell
.venv/Scripts/python.exe -m ruff format tests/test_agent_adversarial.py
.venv/Scripts/python.exe -m ruff check tests/test_agent_adversarial.py
.venv/Scripts/python.exe -m pytest tests/test_agent_adversarial.py -q
```

结果：**13 passed，9.85秒**；Ruff检查通过。存在1项上游 `StarletteDeprecationWarning`，为 TestClient 使用 httpx 的弃用提示。测试采用独立临时数据库及明确命名的 `UnavailableMap` 测试替身，无网络、无真实旅行数据、无生产数据修改，未把替身称为在线高德证据。

覆盖事实：

1. 用户重复候选去重，保留必去标记，不重复安排，不调用未授权地图。
2. 本地时间线不把规划预留或用户开始时间标为 Provider 交通事实。
3. 模拟进程在初始提交后中断：超过租约的 running 转为 failed，保留恢复事件，不静默重做可能收费的请求。
4. 保留旧 ORM 读取结果并模拟另一请求修改及确认：旧凭证不能冒充新版本的成功保存，正式档案只有一份。
5. 显式超时替身两次失败后仍为 information_missing、needs_input，拒绝确认。
6. 费用未知时费用下界0不等于预算通过；未另行确认未知条件不能保存。
7. NaN、正无穷和负无穷坐标分别在执行工具前拒绝（3项）。
8. 来源记忆被删除时，未确认故事连同用户编辑正文撤回，来源清空、版本增加、旧确认失效，列表不再返回旧正文。
9. ready/clean媒体集合变化也撤回未确认故事并拒绝旧确认，不外传私人数据。
10. **已确认故事是独立私有快照**：删除来源不会自动删除已确认档案。该行为已实测，必须披露，不能称为级联清除。
11. 非法来源请求首次404，同一请求回放为failed，不产生正文或正式档案，不伪装成功。

## 代码复核

- `auth.py:get_actor` 默认拒绝未配置或无效令牌；actor由服务端配置决定，旧username路径、查询及JSON再次核对。业务路由挂载身份依赖。静态owner令牌不等于完整多人账号系统。
- `agent/tools.py` 使用固定地图客户端及固定DeepSeek端点，不接受任意URL或代码工具。模型输出仅为受限检索关键词，不提供坐标、票价或交通事实。默认外部调用关闭，故事模式禁止外传。
- 用户候选保持 `user_provided`；地图候选要求有限坐标、城市行政区、POI ID、查询时间。消费均价不当门票，交通异常保持未知。
- `planner.py:validate_plan` 根据最终时间线独立检查唯一地点、必去、结束时间、已知开放窗口、时间传播和费用下界。未知交通只留明确的30分钟规划缓冲，无法保证的完整旅行条件保持 conditional。
- 确认绑定用户、run、revision、摘要和期限；修改使旧确认失效；CAS更新及run唯一档案约束保护并发写入。重复确认不重复生成档案。
- 中断任务有界失败，迟到执行者不能覆盖恢复状态。未确认故事在GET、列表或确认前检查来源更新时间及可用媒体指纹，变化后撤回正文。
- 新前端以Vue插值显示用户文字，未发现原始HTML执行。Agent地图未授权外部服务时显示“非导航底图”的坐标示意，顺序线不冒充实际道路。

## 保留限制

- 无真实地图、模型、ComfyUI、Redis、对象存储和生产PostgreSQL联调，本轮不能证明第三方生产可用性或许可已验收。
- 单机令牌缺多账号生命周期、独立会话撤销、角色及生产限流；不能直接扩大为多人公开部署。
- 原有媒体和图片队列仍为BLPOP，缺可靠ACK/租约；新Agent的执行租约不等于解决旧worker中断恢复。
- 原有删除仍有数据库与对象存储跨系统事务及补偿风险；旧人工业务preview/confirm不等于新Agent摘要凭证。新Agent不提供删除、购买或公开发布工具。
- Agent确认CAS有并发测试，但没有在真实PostgreSQL上证明来源修改、媒体变化与确认的全部竞态串行化语义；多人写入前需锁、隔离或版本条件的集成压力测试。
- 已确认故事保留独立快照，删除来源不等于删除所有派生资料；尚无全部派生数据的一键删除功能。
- 本版最多4天、12候选，使用确定性分组和近邻排序；未完成立项书中的约束k-medoids、跨日ILS、精确解对照或算法优越性实验，不宣称全局最优或量化效果。
- CodeArts真实使用不在本次Codex证明范围内；Git提交、测试日志及本报告不能代替码道开发证据。

建议验收口径为可复现的本地受控旅行工作流原型。在线Provider及多人生产化单列验收；前端完整链路与最终构建以主负责人运行报告为准。
