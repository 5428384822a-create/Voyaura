# 第三轮实页体验说明

当前开发服务无需重启API，刷新浏览器即可看到本轮界面。继续使用原来的访问令牌连接自己的档案。

## 直接进入

- 旅行足迹：<http://127.0.0.1:5188/journey/map>
- 城市记忆：<http://127.0.0.1:5188/journey/stories>
- 影像创作：<http://127.0.0.1:5188/studio>
- 本地截图对照：打开本目录 `index.html`。其中按钮仅切换截图，产品交互请使用上述实际地址。

## 从空档案走通记忆和故事

1. 在“旅程”点击“记录一次抵达”。这里先打开手动选择，不自动申请定位权限。
2. 选择自己实际去过的城市。当前本地索引为厦门、杭州、成都、广州、上海、北京；这六城无需在线地图Key。其他城市继续使用原有在线搜索，失败会如实显示。
3. 查看城市预览，再点击“确认点亮”。这一步会向你的私人档案写入一条手动到访声明，不证明设备在场。若只是查看改稿效果，关闭预览即可，不必确认。
4. 点击“查看城市档案”→“写一段记忆”，填写真实的发生日期、标题和正文，预览后主动确认保存。城市面板支持Escape关闭，手机内页可滚动。
5. 点击“整理这座城的故事”。系统带入城市及最近一条记忆的日期；先核对时间范围，再勾选读取许可并生成。只整理已有资料，缺资料不会补编经历。
6. 查看原始记录，编辑故事；改动后先保存草稿修改，再核对当前版本摘要并主动确认收藏。返回按钮回到城市记忆书架。

保存计划、手动到访、原始文字记忆与整理后的故事是不同记录。生成计划不会自动点亮城市；故事保存不会自动公开发布。

## 照片与创作

在城市档案为记忆添加自己的照片。可用照片会显示“风格创作”；点击后继续使用已有风格预览和确认流程。影像作品页可浏览真实任务状态、原片来源、成功作品对比、收藏与下载。

当前本机尚未完成对象存储、媒体处理和影像生成服务的在线联调。页面不会伪造可用照片或生成成功；当前创作页的海岸摄影明确为灵感参考，非个人作品。无照片时仍可完整体验手动记录、文字记忆与本地故事整理。

## 可复现验证

在 `web` 执行 `npm run test` 与 `npm run build`；在仓库根目录执行 `api/.venv/Scripts/python.exe scripts/verify_e2e.py`。运行器创建独立数据库与随机访问令牌，不读改个人档案。Playwright现在要求明确的测试环境，避免直接运行时误写当前档案。

测试报告、当前服务只读截图和独立测试库流程截图分开保存；详见 `REVIEW.md` 与 `../../delivery/TEST_REPORT.md`。实际开发工具为Codex，未将本轮记录冒充CodeArts。
