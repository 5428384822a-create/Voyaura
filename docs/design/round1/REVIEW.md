# Voyaura 第一轮前端改稿审阅

日期：2026-11-23。独立分支：`codex/competition-ui-round1`；工程基线：`b525185`。

## 本轮实际完成

以概念图的发现／规划首页为主要视觉参考：暖白底、橙红品牌、旅行摄影、中文层级、功能快捷入口、目的地卡片与小曦任务侧栏。重新实现公开发现首页、顶部品牌导航和手机固定底栏，统一“发现／计划／旅程／创作／我的”五项导航。手机目的地卡片可横向滑动，整页不横向溢出；支持键盘焦点和减少动画偏好。

搜索支持六座现有城市；明确城市时保留原输入，主题或多城歧义先让使用者选择目的地。当前不是全国 POI 检索。目的地卡片的城市、旅行想法、兴趣、节奏和天数会带入现有 Agent 规划；未连接时先请求连接，成功后继续原任务。旅行想法存于浏览器 history state，不放进地址栏，支持当前历史项刷新；它不是服务端保存的行程。

公开首页无需令牌，不自动打开连接窗口，也不请求私人 API。进入私人流程时仍通过真实身份校验；现有计划／故事的来源、未知信息、授权和主动保存确认保持有效。没有自动创建城市足迹或旅行故事。

## 两个实际页面方案，待用户选择

- A 清爽发现：<http://127.0.0.1:5188/>。暖白渐变，搜索优先；当前默认预览，更接近概念图。
- B 摄影沉浸：<http://127.0.0.1:5188/?style=immersive>。同一真实照片，深色渐变与白色标题，城市影像更突出。
- [桌面＋手机对比图](comparison.png)；[可折叠截图审阅页](index.html)。全部取自本地 Chrome 实际页面，未绘制虚构交互效果。

B 的查询参数仅用于开发环境视觉比较，生产构建默认 A。默认值不代表用户已选择；本轮没有擅自确定最终设计方向。可后续考虑缩短封面，让手机上的目的地更早出现，尚未实施该第三种取舍。

验收建议：先比较两版的照片和文字清晰度，再试主题筛选和不含城市的旅行想法，最后点杭州卡片验证城市条件带入。无需连接即可比较首页；私人规划使用本机 `.local/access-token.txt` 中的令牌，勿把令牌放入反馈或截图。

## 素材与工程边界

照片来自 Wikimedia Commons，均为真实实景摄影、保留作者／许可和处理说明；本地 WebP 单张小于 300 kB。照片仅是编辑旅行灵感，不代表用户抵达、实时天气或景点开放情况。见 [素材来源](ASSET_SOURCES.md)，网页有“影像署名与许可”入口。

增加 vue-router 以支持刷新和返回；保留 App 原业务控制器，页面路由按名称选择现有视图。本轮没有拆分整体后端或改数据库。HTML history 模式在生产托管时需要 SPA 回退，见根目录 RUNBOOK.md；尚未公开部署。

“旅程”目前通向现有真实地图，“旅行记忆”进入原有故事流程，“我的”打开本机私人档案连接窗口。计划长表单／结果页、地图／记忆／创作的全面视觉统一留到下一轮。本轮不代表完整账户中心、全国检索、在线模型或云地图联调已经完成。

旧 `docs/delivery` 工程证据保持原版本；本轮报告和截图独立放在本目录，CI 浏览器产物路径同步更新。API 未改动，本轮不冒称重跑后端 101 项。全部改稿与验证记为 Codex 工作，不构成 CodeArts 实际使用证据。未推送、合并、公开部署或提交比赛作品。
