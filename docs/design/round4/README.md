# 第四轮：全流程体验与参赛演示打磨

本轮方案已经直接实施。刷新当前产品即可使用，无需重新启动API。

## 直接体验

1. 打开 <http://127.0.0.1:5188/account>，或点击导航“我的”。未连接时先看使用引导，不读取私人记录；点击连接后使用原本机访问令牌。
2. 从“安排下一段旅程”“留下抵达与记忆”“把回忆连成故事”选择入口。未配置在线地点时，规划页仍可主动填入离线演练条件，再点击开始生成。
3. 已连接的“我的”会展示实际读取的城市／记忆／照片数量、最近四条任务和服务配置状态。点击最近任务，只读取原任务及版本；不会重新生成、授权外部调用或自动确认。
4. 直接打开故事地址时，城市与日期会在验证后保留。例如 `/journey/stories?compose=story&city=350200&date=2026-06-08`；读取授权默认关闭。原任务链接使用 `run` 参数，刷新后继续读取同一任务。
5. 编辑规划、故事或文字记忆后离开，页面会提醒未保存的修改。选择“继续编辑”保留输入；主动放弃后才离开。刷新／关闭窗口使用浏览器原生提醒。未提交正文仅在当前页面内存中保留。

## 本轮界面

- “我的”从连接弹窗与占位页升级为真实档案总览；连接设置单独保留。
- 最近任务区分执行中、待补充、待核对、已保存和失败，恢复原始版本。
- 服务配置与在线成功分开表达：已配置仍需用户授权，在线结果以实际执行为准。
- 登录、返回与任务类型切换保持路由上下文；未登录时不会先挂载私人工作台发起请求。
- 未保存提醒默认聚焦“继续编辑”，支持Escape；嵌套编辑时暂停底层焦点处理。

## 证据与隐私

`index.html` 是截图对照页，按钮只换图。实际操作使用上方产品地址。

`after/` 来自当前5188服务，只有GET，没有写入操作；截图中的身份与任务文字已遮盖。完整任务与编辑保护截图位于 `account-screenshots/`，来自隔离测试库，测试文字均标为本地验收输入，不是真实旅行。

使用根目录 `api/.venv/Scripts/python.exe scripts/verify_e2e.py` 复现真实HTTP验收；前端在 `web` 执行 `npm run test`、`npm run build`。测试、构建与四屏宽结果见 `validation.json`、JUnit及 `REVIEW.md`。

当前仍是本机owner访问令牌体系。在线高德／模型／影像生成、完整媒体栈与CodeArts实际开发证据按既有计划单独验收，本轮未将其包装为完成。
