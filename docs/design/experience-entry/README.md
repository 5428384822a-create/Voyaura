## 现在如何体验

1. 刷新真实规划页，在顶部提示中点击“填入离线演练条件”。这一步只填表，不创建任务，可点击“恢复我之前的输入”撤回表单替换。
2. 在出现的“离线演练 · 虚拟地点”说明中点击“开始演练”，由真实后端规则规划四个虚拟地点；地图／模型调用均保持关闭。
3. 结果出来后，查看每日安排、地点地图和执行记录。宽屏显示时间线与地图同屏；可点击编号体验联动，手机保持切换视图。
4. 若要体验保存，点击“核对并保存当前草案”，阅读摘要和虚拟演练说明，主动勾选条件承认后再确认。确认前不会写入正式档案；确认后标题与输入均保留“离线演练”标记，不增加城市足迹。

演练使用虚拟地点和示例坐标，不是真实景点攻略或实际出游记录。真实景点自动检索仍需配置高德服务。离线规则验收不代表在线大模型或高德已经接通。

## 本次修复

- 在生成前显示地点来源缺口，说明为何无法进入结果态；授权未配置的服务不能代替实际连接。
- 增加可撤回的演练填表入口。用户主动生成后，调用原POST /agent/runs，再通过原PATCH draft接口将标题明确标为离线演练；保存继续使用原有二阶段确认。
- 演练条件强制关闭外部模型、地图查询和记忆读取，名称、输入和持久化标题均保留虚拟标记；标记写入中断会报错，并允许使用同一请求号重试，不伪造完成。
